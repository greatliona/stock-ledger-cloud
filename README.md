## L1.5.95 資產類別總和顯示可計算的 DPnL

- 資產類別總和圓餅缺少部分昨值時，顯示有資料的分項合計並標記「（部分）」，不顯示全體百分比。滑過看已計入的金額、缺項及原因；完全無法比較才顯示「DPnL —」。
- 合計仍按未截尾金額計算，已知的台幣、美元、USDT 現金變動照常計入。允許既有帳本支援的美元負餘額參與比較；其他圓餅、折線及帳本資料不變。

## L1.5.94 圓餅與分項 DPnL 使用相同比較基準

- 修正 L1.5.93 混用「逐檔最後紀錄價」與「每日結帳分類總額」的錯誤。圓餅 DPnL 現在直接加總分項未截尾金額；台股圓餅＝台股 DPnL＋台幣現金 DPnL，加密圓餅＝合約 DPnL＋USDT 現金變動。
- 資產類別圓餅含各市場 DPnL 及台幣／USD／USDT 現金變動，各計一次；美股持股圓餅只計美股 DPnL。外幣現金與持倉統一用目前台幣匯率，避免混入另一份結帳匯率。
- %＝合計 DPnL／（目前圓餅總額－合計 DPnL）；金額加總後才截尾，不平均或相加百分比。滑過可查看各分項金額及公式。
- 缺少任一必要分項基準顯示「DPnL —」及缺少原因，不冒充完整合計。空持倉視為零部位；零／無效百分比分母不製造無限大。
- 此為畫面分項 DPnL 的合計，包含現金流；不再將其稱為每日結帳總額差額。持倉、折線、現金及摘要的既有 DPnL 不變，帳本紀錄與查價不變。

## L1.5.93 圓餅圖獨立計算含現金的 DPnL

- 修正圓餅圖沿用折線／分類 DPnL 的問題，改為「目前圖內總額 − 前一日同範圍每日紀錄總額」，百分比除以前一日該範圍總額。
- 台股圓餅包含台股及台幣現金；加密包含合約權益及 USDT；資產類別圓餅包含所有圖內資產與現金；美股持股圓餅不含未繪入的美元現金。
- 因為比較的是整個配置範圍的總額，含其中的現金／USDT 變動、持倉與匯率變動。圓餅內股票和現金等額互轉不會憑空產生損益；不是直接相加或平均兩個百分比。
- 缺少前一日完整同範圍紀錄時顯示「DPnL —」，不拿純台股數字冒充含現金的結果；零基期只顯示有效金額，非零變動率為「—」。
- 台股折線、現金折線、資產總和及持倉 DPnL 的既有規則不變；不修改帳本或新增查價請求。

## L1.5.76 每個持倉的今日漲跌

- 台美股市值下、基金目前總額旁、加密合約成本旁顯示 `今日 +$金額 +X.XX%`，配合既有獲利／虧損顏色；手機空間不足會換行。
- 使用台灣日期的前一曆日最後一次儲存價。每天開啟帳本和儲存變更時保留當日最後觀察，獨立放在 `dailyPriceHistory`，隨原本帳本 JSON 的本機／雲端同步、匯出及匯入保存。不新增查價請求，也不更動資料庫結構或權限。
- 台美股／加密金額 =（目前價 − 昨日紀錄價）× 目前數量 × 方向 × 目前台幣匯率；台股匯率為 1。% = 價格變動率，空單反向；不是成本報酬率或槓桿報酬率。不把數量增加、保證金增加或匯率本身變動算成價格獲利，亦不包含今日已實現損益。
- 嚴格比較前一日，不拿更早資料冒充昨價。缺少昨價顯示 `今日 —`；台美股可沿用同持倉 ID 的既有前日結帳價格。更換股票代號後不沿用原股票的新版價格紀錄。
- 基金原本沒有單位數／淨值，僅在前日有總額與相同成本時顯示總額變化；成本變動或缺少可比成本時顯示 `今日 —`，避免把申贖當漲跌。舊的加密紀錄只含權益，不能還原成交價，因此需先累積新紀錄。
- 網頁關閉期間不會自行取得或補造價格；這是使用者最後儲存價的比較，不是交易所官方昨日收盤漲跌。跨日只刷新標示，不重建正在修改的表單。

- 基金改為緊湊收合卡片，摘要顯示名稱及損益。
- 基金與合約預設唯讀，修改後須按儲存；取消不保存，刪除保留確認。

## L1.5.13 折線圖目前總值

- 六個折線圖標題旁顯示小灰字目前總值，沿用摘要金額並隨資料更新。
- 包含合併市值、現金、台股、美股、基金及加密合約；不改圖表繪製及計算。

## L1.5.12 分類總值與交易紀錄置中

- 交易紀錄全部欄位標題、內容及操作按鈕置中。
- 台股、美股、基金、加密合約標題旁新增灰字目前總值，與上方摘要使用相同金額；現金不新增。

## L1.5.11 股票名稱呈現

- 交易紀錄股名及股號上下排列並置中；股號使用較小鐵灰字，不再顯示斜線。
- 美股僅顯示 ticker，空單標記保留。
- Excel 股名、股號／Ticker 分欄，美股股名欄留白。

## L1.5.10 交易紀錄

- 日期統一 YYYY/MM/DD；前四欄為賣出、買入、持有天數、股名／股號，Excel 同步。
- 持有天數是兩日期的日曆天差，同日為 0 天。
- 手機交易卡片緊密三欄排列，長字串可換行，避免金額溢出。

## L1.5.9 手機新增表單

- 手機新增表單改為緊湊雙欄；新增按鈕與最後一個輸入欄並排，多空選單維持在加號左側。
- 僅調整 640px 以下排版，桌面版及損益算法維持不變。

## L1.5.8 新增列精簡

- 台股、美股、基金、合約的新增按鈕統一顯示 `+`。
- 多空選單移至 `+` 左側，台股與美股輸入列不再因方向選單增加一行。

## L1.5.7 個股做空

- 新增台股、美股時可選擇做多或做空；舊資料預設做多。
- 空單代號後顯示 `(short)`，損益為（建倉價 − 現價／平倉價）× 股數；美股依帳本匯率換算台幣。
- 空單在持股總額、每日結帳和配置圖採「建倉名目金額＋未實現損益」的簡化帳面價值，不代表券商保證金權益；不含借券費、手續費或稅。
- 交易紀錄沿用原有買入／賣出欄位；空單分別代表建倉／回補日期及價格。匯出 Excel 保留空單標記及反向損益。
- 回歸測試：`node short-position.test.cjs`。
