# 股票記帳本雲端版

## L1.5.28 明確分盤查詢與成交新舊提示

- 每個代號分別指定 NORMAL、BEFORE、AFTER、OVERNIGHT 查詢；不再依賴省略 period 的預設結果。四份結果依實際成交時間合併選價，若服務忽略盤別篩選則明確提示。
- 成交距查詢超過 5 分鐘會提示資料年齡；這是提示門檻，不等於證實行情延遲，休市時也可能出現。部分盤別失敗仍可取得其他有效成交，但不宣稱全盤別已驗證。
- 不以買賣掛單或查詢時間冒充成交，不讓較舊成交覆寫已存的較新富途報價。
- 最多每代號 4 次唯讀請求（7 檔 28 次），循序間隔 0.3 秒，整批 120 秒上限，HTTP 429 立即停止。只在按 reload 時執行，不購買或訂閱付費行情。
- Secrets 不變、其他版面不變。新增盤後優先、SEMI 舊成交、盤別不符、限流與逾時測試；尚未使用使用者憑證實測，不能宣稱盤後即時或 SEMI 延遲原因已驗證。

## L1.5.27 含盤後／夜盤的最新成交價

- 美股改用富途 rt-ticker 逐筆成交介面，依實際成交時間取最新價格，包含盤前、正常盤、盤後、夜盤。
- 不再從多個快照盤別猜測最新價，也不將正常盤 data_time 當作盤後成交時間。
- 此官方端點一次一檔；代號去重、循序請求、間隔 0.3 秒，HTTP 429 即停止剩餘請求，無無限重試。
- 查價仍為按鈕觸發，不是持續串流；顯示真實成交時間，無新成交時時間不會變成按鈕點擊時間。
- Secrets 不變；私鑰密碼仍選用，手機高度修正保留。
- 假資料測試驗證選價、GET 簽章、七檔請求與失敗保護。未使用真實金鑰驗證逐筆行情權限。

## L1.5.26 私鑰密碼改為選用

- 未加密 Ed25519 私鑰只需 AppKey ID 與私鑰，不需要 private_key_password。
- 接受完整 PEM 或完整 Base64 PKCS#8 私鑰；公鑰及無效內容仍拒絕。
- 已加密私鑰仍須原解密密碼；不將私鑰傳入網頁或輸出至日誌。
- 手機捲動修正保留，其他版面與持股資料不變。設定見 FUTU_SETUP.md。

## L1.5.25 手機頁面捲動與既有私鑰加密

- 報價橋接頁依帳本實際內容同步內外層高度，取代固定 1800px；展開／收合、畫面旋轉後重新量測。
- 提供 futu_encrypt_key.py，將既有 Ed25519 私鑰加密而不改變公鑰配對；不覆蓋原檔。
- 連帶修正長頁面雙層 iframe 的交易確認視窗定位，依最外層可見區域置中。
- 隔離瀏覽器實測 390／430px 手機寬度與 1280px 電腦寬度可到達頁尾，展開／收合高度會同步；並非實體 iPhone 驗證。
- 設定教學見 FUTU_SETUP.md。測試不使用正式帳本或實際富途憑證。

## L1.5.24 富途 REST 報價

- 美股 reload 已改用富途官方 REST 批次報價，移除 yfinance 依賴及 Yahoo 備援。
- 使用伺服器 Secrets 中的 AppKey + Ed25519 加密私鑰；提供本機金鑰產生工具。
- 設定與取得 API 步驟：[FUTU_SETUP.md](FUTU_SETUP.md)。
- 僅查價，不下單、不購買行情、不更動其他版面；真實報價仍待使用者設定富途憑證驗證。

以下為歷史版本紀錄，Yahoo 說明不再適用目前版本。

## L1.5.23 限流請求控制（不代表雲端限流已解除）

- 夜盤模式涵蓋本批所有代號時只發一次批次查詢，不再補查無用的盤後快照。
- 偵測限流後立即中止後續批次與外層重試，所有工作階段共用 120 秒冷卻；rerun 不清除冷卻。
- 本機及模擬測試驗證請求控制，未部署或證明正式站 Yahoo 限制已解除。

## L1.5.22 報價部分失敗處理

- 夜盤查詢成功時，不再因輔助盤前盤後查詢失敗而丟棄有效報價。
- 連線失敗最多嘗試兩個 Yahoo 主機；遇到限流停止重試。錯誤顯示類型或 HTTP 狀態，日誌不記錄 cookie、crumb 或帳戶資料。
- 本機隔離頁以假持股驗證夜盤更新與損益重算；尚未確認正式站原始失敗原因，不能保證正式站已恢復。

## L1.5.21 報價版本一致性

- Streamlit 每次 rerun 重新載入報價模組，避免新版前端搭配快取的舊分鐘價後端。
- 回傳必須含 overnight-v1 協定與有效時段；舊回傳不更新持倉，明確要求重啟服務。
- 部署後請 Reboot Streamlit app 並重整瀏覽器，確保既有工作階段切換版本。

## L1.5.20 夜盤報價修正

- 改用 Yahoo quote API，明確要求 overnightPrice=true，並與正常盤、盤前、盤後報價按時間比較，取最新有效值。
- 每檔顯示實際報價時間與時段，不再只顯示最早時間。夜盤時缺少近 15 分鐘夜盤報價則保留原價並提示，不使用舊盤後價冒充夜盤。
- 無新增付費服務或 API Key；Yahoo 仍可能延遲、缺漏，不能保證與券商逐筆同步。使用 yfinance 1.0 的內部資料介面，升級依賴時需重跑報價測試。

## L1.5.19 美股更新與圓箭頭

- 美股新增列 + 右側加入大圓箭頭，一次更新持倉現價與損益；縮短 ticker 欄位。
- 加密更新按鈕同步採用 26px SVG 圓箭頭。
- Streamlit 後端透過 yfinance 抓最新可用一分鐘收盤價，包含可用盤前盤後資料。顯示報價時間，不保證無延遲。
- 免 Key、無新增付費服務、只按需查價。Yahoo 可能限流；失敗保留原價，不使用付費備援。
- quote_bridge 是同專案內的 Streamlit 通訊元件，部署必須一併包含；純靜態預覽不支援美股查價。
- 本機待修改價格不覆寫、查價請求間隔至少 15 秒、單次最多 50 個不重複代號。
- Yahoo 資料僅供個人用途，使用需符合資料提供者條款。

## L1.5.18 手動更新合約行情

- 修改旁新增 ↻，點擊一次向幣安公開 USD-M 合約 ticker 請求一次最新成交價並重算損益。
- 不需 API Key、不交易、不輪詢、不使用付費 API 或代理；只傳送合約代號。
- 支援完整 USDT 合約代號；失敗／逾時保留原價，不退回現貨價。強平價維持手動。
- 請求中防連點、修改中停用更新，卡片顯示結果。地區及瀏覽器網路限制可能造成失敗。

## L1.5.17 合約卡片整齊化

- 統一灰色標籤、深色數值及靠左對齊；價格與部位摘要使用三欄。
- 移除重複數量及損益資訊，保留頂部損益、底部成本與操作按鈕。
- 操作按鈕改為正常排版，避免絕對定位遮住金額。

## L1.5.16 強平價欄位排版

- 開倉價、目前價、強平價依序同列三欄，窄版欄位可縮，保持緊湊。

## L1.5.15 強平價位置

- 強平價標題移除單位及選填字樣，欄位移至目前權益後方；其他功能不變。

## L1.5.14 合約強平價與基金收合

- 加密合約新增選填手動強平價，不影響損益計算。
- 基金改為緊湊收合卡片，摘要顯示名稱及損益。
- 基金與合約預設唯讀，修改後須按儲存；取消不保存，刪除保留確認。

## L1.5.13 折線圖目前總值

- 六個折線圖標題旁顯示小灰字目前總值，沿用摘要金額並隨資料更新。
- 包含合併市值、現金、台股、美股、基金及加密合約；不改圖表繪製及計算。

## L1.5.12 分類總值與交易紀錄置中

- 交易紀錄全部欄位標題、內容及操作按鈕置中。
- 台股、美股、基金、加密合約標題旁新增灰字目前總值，與上方摘要使用相同金額；現金不新增。

## L1.5.11 股票名稱呈現

- 交易紀錄股名及股號上下排列並置中；股號使用較小鐵灰字，不再顯示斜線。
- 美股僅顯示 ticker，空單標記保留。
- Excel 股名、股號／Ticker 分欄，美股股名欄留白。

## L1.5.10 交易紀錄

- 日期統一 YYYY/MM/DD；前四欄為賣出、買入、持有天數、股名／股號，Excel 同步。
- 持有天數是兩日期的日曆天差，同日為 0 天。
- 手機交易卡片緊密三欄排列，長字串可換行，避免金額溢出。

## L1.5.9 手機新增表單

- 手機新增表單改為緊湊雙欄；新增按鈕與最後一個輸入欄並排，多空選單維持在加號左側。
- 僅調整 640px 以下排版，桌面版及損益算法維持不變。

## L1.5.8 新增列精簡

- 台股、美股、基金、合約的新增按鈕統一顯示 `+`。
- 多空選單移至 `+` 左側，台股與美股輸入列不再因方向選單增加一行。

## L1.5.7 個股做空

- 新增台股、美股時可選擇做多或做空；舊資料預設做多。
- 空單代號後顯示 `(short)`，損益為（建倉價 − 現價／平倉價）× 股數；美股依帳本匯率換算台幣。
- 空單在持股總額、每日結帳和配置圖採「建倉名目金額＋未實現損益」的簡化帳面價值，不代表券商保證金權益；不含借券費、手續費或稅。
- 交易紀錄沿用原有買入／賣出欄位；空單分別代表建倉／回補日期及價格。匯出 Excel 保留空單標記及反向損益。
- 回歸測試：`node short-position.test.cjs`。

```toml
[app]

[supabase]
url = "你的 Supabase Project URL"
anon_key = "你的 Supabase anon key"
table = "stock_ledger_state"
row_id = "main"
```
