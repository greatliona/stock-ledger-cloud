L1.5.1

- 台股與美股新增買入日期；新持股預設為新增當日，既有持股統一補為 2026-09-05，並可在持股修改區更正。
- 刪除台股或美股時改為三選一：建立交易紀錄、直接刪除但不紀錄、取消。
- 建立交易紀錄時可確認或修改買入日、賣出日、股數、平均成本、賣出價格與美股賣出匯率，畫面即時計算總成本、賣出金額、獲利與獲利%。
- 頁面最下方、資料備份上方新增預設收合的交易紀錄區，可依市場與賣出月份篩選。
- 每筆交易紀錄可修改；刪除交易紀錄前會再次確認，且不會把股票加回持股。
- 全部交易紀錄可匯出成 Excel，包含台股／美股、原幣與台幣金額、獲利與合計。
- 交易紀錄與買入日期都包含在既有 JSON 備份及 Supabase 同一份 state 資料中，不需要新增資料表或修改 SQL。
- 交易紀錄表在桌機使用完整欄位表格，在 iPhone 與中尺寸螢幕改為卡片，避免水平裁切。
- 既有持股、每日紀錄、折線圖、圓餅圖與其他排版不變。
